InsurCraft portable mode

While this file sits next to insurcraft.exe, InsurCraft keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the InsurCraftData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move InsurCraft with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\InsurCraft and
%LOCALAPPDATA%\InsurCraft) instead. If InsurCraftData can't be written (for example on a read-only
drive), InsurCraft says so and uses the per-user folders instead.
